# MovieFinder

Приложение для поиска фильмов на чистом JavaScript (Vanilla JS) с использованием OMDb API. Позволяет находить фильмы по названию, просматривать карточки и открывать подробную информацию в модальном окне. Учебный проект, написанный самостоятельно.

**Демо сайта:** https://movie-finder-psi-tan.vercel.app

![Скриншот](screenshot.png)

## Что умеет

- Поиск фильмов по названию с валидацией поля ввода (сообщение об ошибке при пустом запросе)
- Отображение результатов в виде адаптивной сетки карточек с постером, названием и годом выпуска
- Открытие модального окна с подробной информацией о фильме (режиссёр, актёры, жанр, длительность, рейтинг, описание)
- Обработка ошибок: информирование пользователя, если фильм не найден или произошла сетевая ошибка
- Безопасный рендеринг: создание DOM-элементов через `createElement` и `textContent` (защита от XSS)
- Заглушка для постеров: если у фильма нет постера (API возвращает `"N/A"`), подставляется картинка-плейсхолдер
- Блокировка скролла страницы при открытом модальном окне
- Индикатор загрузки во время ожидания ответа от сервера

## Технологии

HTML5, CSS3 (Grid, Flexbox, Media Queries), JavaScript (ES6+)

Fetch API, `async/await`, обработка ошибок через `try/catch/finally`, OMDb API.
